# public/signs/

Place ISL sign images or animated GIFs here.

Filename must exactly match the word key from config/words.json (uppercase):

  HELLO.gif
  THANK_YOU.gif
  YES.gif
  NO.gif
  PLEASE.gif
  SORRY.gif
  HELP.gif
  WATER.gif

Supported formats: .gif (animated), .png, .jpg, .webp

If a file is missing, the app shows an emoji placeholder automatically.
No crashes, no broken images — the app handles missing assets gracefully.
